# ScoutCard - Especificação

## Objetivo

Transformar um nome de jogador em uma decisão informada no menor tempo possível.

---

# Fluxo

Selecionar nome

↓

Abrir ScoutCard

↓

Buscar dados

↓

Atualizar popup

↓

Salvar em cache

---

# Plataforma

Desktop

Userscript (Tampermonkey)

---

# Ativação

Seleção de texto.

Não utilizar hover.

---

# Fonte principal

Transfermarkt

---

# Fonte secundária

Sorare

---

# Fonte complementar

The Analyst

---

# Cache

IndexedDB

---

# Filosofia

Sempre utilizar dados estruturados quando possível.

Evitar scraping visual.

---

# Regras

- Código simples
- Uma funcionalidade por vez
- Cada versão deve funcionar
- Evitar dependências externas
