# ScoutCard

ScoutCard é um userscript para desktop que transforma um nome de jogador em informações úteis para managers do Sorare.

Basta selecionar o nome de um jogador em qualquer página da web.

O ScoutCard busca informações automaticamente e exibe um card compacto ao lado da seleção.

## Objetivos

- Funcionar em qualquer site
- Não depender de instalação complexa
- Abrir rapidamente
- Utilizar cache local
- Ajudar managers do Sorare a tomar decisões rapidamente

## Fontes de dados

- Transfermarkt (principal)
- Sorare
- The Analyst (opcional)
